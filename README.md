# Pascal-Limassol

Хранилище Obsidian для семьи ученика Makar Urvantsev (PASCAL Private Secondary School Lemesos, Year 1, класс 1B, 2026–27): все сообщения школы, важные документы и две базы знаний.

## Структура

| Папка | Что внутри |
|---|---|
| `Messages/` | Оригиналы сообщений от Pascal. `index.md` — общий индекс `datetime \| source \| topic \| link` (новые сверху). |
| `Messages/mail/` | Письма Gmail от Pascal простым списком: файл на письмо (или диалог), вложения — в `Messages/mail/attachments/`. Подпапка `DONE/` — обработанные пользователем письма. |
| `Messages/edu portal/` | Сообщения портала edu4schools простым списком (без папок по учителям), вложения — в `Messages/edu portal/attachments/`. Подпапка `DONE/` — обработанные пользователем сообщения. |
| `Files/` | Самые важные долгоживущие вложения, актуальные весь учебный год (календарь, расписание, навигационный пакет, учителя, меню, автобус, клубы, форма, цены). Держатся в актуальной версии — при выходе новой старая заменяется. Временное (ДЗ, revision worksheets) сюда не попадает. |
| `<YYYY-MM-DD> KNOWLEDGE BASE/` | Суммаризация **всей актуальной** информации из сообщений (русский). Дата в имени = дата последней суммаризации. |
| `<YYYY-MM-DD> PUBLIC/` | То же, но только общее для школы и класса 1B, **без** индивидуальных данных ученика и семьи. Дата в имени = дата последней суммаризации. |

## Именование сообщений

- Gmail (`Messages/mail/`): `<YYYY-MM-DD> <TOPIC>.md`
- Портал (`Messages/edu portal/`): `<TEACHER> <YYYY-MM-DD HH-MM> <NAME>.md` — имя учителя (`Фамилия Имя`, как на портале) в начале имени, например `Stephanou Andreas 2026-10-09 07-07 Mathematics Test Revision Worksheet 1.md`.

- Статуса в имени нет: статус «обработано» определяется только нахождением файла в папке `DONE/`.
- `YYYY-MM-DD` — дата сообщения; `TOPIC` — тема/название сообщения.
- Вложение вставляется в сообщение кликабельной ссылкой на файл в `attachments` своего источника.
- Сообщения одного диалога допустимо объединять в один файл с перечнем сообщений.

## Статус и папка DONE

- Статус определяется только местом файла: лежит в `DONE/` — сообщение обработано; лежит в корне `Messages/mail/` или `Messages/edu portal/` — ещё нет. Новые сообщения всегда создаются в корне. Имя файла статус не содержит.
- В папку `DONE/` сообщения перемещаются **только по запросу пользователя** командой `/pascal-done`: она показывает чек-лист всех сообщений не из `DONE/` (по умолчанию все выбраны), и после подтверждения переносит выбранные и обновляет ссылки.
- Сообщения в `DONE/` — полноправные источники: при анализе, суммаризации и обновлении баз знаний к ним обращаются так же, как к сообщениям в корне; поиск и дедупликация всегда охватывают и корень папки, и `DONE/`.

## Индекс

`Messages/index.md` поддерживается актуальным; пример строки: `| 2026-10-05 10:15:01 | portal | New menu for October | [[…\|open]] |`. Gmail-время — UTC, портал — локальное (UTC+3).

## Базы знаний

- Основной текст без подсветки: изменения вносятся сразу в текст, неактуальное исправляется или удаляется.
- Обе базы должны соответствовать друг другу и актуальному статусу; PUBLIC лишь не содержит индивидуальной части (профиль ученика, оплаты, отсутствия, документы, пароли).
- После каждой суммаризации обе папки переименовываются на текущую дату, а ссылки обновляются; `updated:` во frontmatter заметок — текущая дата.

## Обновление

`/pascal-update` (skill `.claude/skills/pascal-update/SKILL.md`) скачивает новые письма Gmail и сообщения портала (нужен открытый и залогиненный в браузере `https://www.edu4schools.com/SP/Main/Home`), обновляет `Messages/`, `Files/`, обе базы знаний и выдаёт отчёт: список писем (новые и уже имевшиеся), список скачанных сообщений портала и суммаризацию изменений.

`/pascal-done` (skill `.claude/skills/pascal-done/SKILL.md`) показывает чек-лист сообщений, которые ещё не в `DONE/` (по умолчанию все отмечены), и после подтверждения пользователя переносит выбранные в `DONE/` источников и обновляет ссылки; запускается только по запросу пользователя.

## Приватность

Паспорта, медицинские данные, сертификаты, пароли и номера документов лежат только в `Messages/mail/attachments/`; в базы знаний их содержимое не переносится, в PUBLIC — тем более.
