# /pascal-update — обновление проекта Pascal-Limassol

Прочитай сначала `CLAUDE.md` и `README.md` в корне хранилища — там структура, правила имён и приватности. Язык заметок баз знаний — русский; оригиналы сообщений — как есть. Хранилище на Mac пользователя: в `device_bash` это `$HOME/mnt/Pascal-Limassol` (= `/Users/igor.urvantsev/obsidian/prv/Pascal-Limassol`). Каждый вызов `device_bash` — новая оболочка; пути, начинающиеся с «2026-…» или «-», берите в кавычки/с `./`.

## Шаг 0. Портал edu4schools открыт?
1. Через `tabs_context` (встроенный браузер, `mcp__remote-devices__Claude_Browser__*`; при отсутствии — загрузить через ToolSearch) проверь, есть ли вкладка на `edu4schools.com`.
2. Если нет — открой `https://www.edu4schools.com/SP/Main/Home` (`preview_start`) и **попроси пользователя залогиниться** (пароли сам не вводить). Дождись подтверждения, затем перейди на `https://www.edu4schools.com/SP/SPChat/Index`.

## Важно про статусы
- Новые сообщения создаются **без статуса** и кладутся в корень `Messages/mail/` или `Messages/edu portal/`. Статус (`DONE`) ставит только пользователь, в папку `DONE/` сообщения переносит **только** skill `/pascal-done` по запросу пользователя — `pascal-update` ничего не переносит в `DONE/`.
- Сообщения в `DONE/` — такие же источники, как остальные: читай их, дедуплицируй по ним и учитывай в базах знаний наравне с другими (поиск всегда рекурсивный).

## Шаг 1. Что уже скачано
- `Messages/index.md` — таблица `datetime | source | topic | link` (новые сверху).
- Дедупликация Gmail — по `gmail_id` во frontmatter всех файлов `Messages/mail/**/*.md` (включая подпапку `DONE/`): `grep -rh '^gmail_id:' Messages/mail --include=*.md`.
- Дедупликация портала — по `teacher` + `date` (frontmatter) во всех файлах `Messages/edu portal/**/*.md` (включая `DONE/`).

## Шаг 2. Gmail
1. `search_threads`: входящие от Pascal (`in:inbox (from:pascal.ac.cy OR from:epafos.gr OR from:pascal)`, при необходимости пагинация/`after:` от последней даты в индексе). Включая уведомления портала от `4schools-info@epafos.gr`.
2. Для каждого письма, чей `gmail_id` отсутствует, — `get_message`. Вложения: `messageFormat: RAW` → большой JSON сохраняется в файл tool-results; декодируй `raw` (urlsafe base64) модулем `email` в python (в облаке), доставь файлы на Mac: `SendUserFile` + `device_commit_files` в `Messages/mail/attachments/` (уже существующие имена не перезаписывать; при конфликте с другим содержимым — добавить суффикс).
3. Сохрани письмо файлом `Messages/mail/<STATUS><YYYY-MM-DD> <TOPIC>.md` (STATUS пустой; TOPIC = тема без `\ / : * ? " < > | # ^ [ ]`, ≤80 символов; при коллизии добавить ` HHMM`; для «Message notification» — `<Учитель> - portal notification`). Содержимое:
```
---
source: gmail
gmail_id: <id>
thread_id: <id>
datetime: YYYY-MM-DD HH:MM
from: "<from>"
subject: "<subject>"
tags: [pascal, message, mail]
---

# <Subject>

**From:** … **To:** … **Date:** … UTC **Subject:** … **Gmail message id:** …

## Body
<текст письма без повторяющихся футеров>

## Attachments
- [имя](attachments/имя%20файла)
```
Вложения-картинки подписи можно сохранять, но не разбирать. Письма одной темы/диалога допустимо объединять в один файл с перечнем сообщений по порядку.

## Шаг 3. Портал
1. Кнопка «Teachers» (`button.btn-primary`, `href="#memberslist"`) открывает список; учителя — `a[href='#']` (искать по `includes` в нормализованном тексте). «More messages» подгружает старые. Каждое сообщение в DOM дублируется — читай по `innerText`, сверяй с индексом по учителю + дате (время портала — локальное, UTC+3).
2. Для каждого нового: `Messages/edu portal/<STATUS> <TEACHER> <YYYY-MM-DD HH-MM> <NAME>.md` — простым списком без папок по учителям; STATUS пустой (имя начинается с `TEACHER`); `TEACHER` = `Фамилия Имя` в обычном регистре (как `Stephanou Andreas`); время портала локальное; `NAME` — тема без `\ / : * ? " < > | # ^ [ ]`:
```
---
teacher: "<ФАМИЛИЯ ИМЯ>"
subject: "<предмет>"
date: YYYY-MM-DD HH:MM:SS
source: edu4schools messages
tags: [edu-portal, message]
---

# <Title>

**От:** … · **Кому:** URVANTSEV MAKAR · **Дата:** …

<текст>

## Attachments
- [[Messages/edu portal/attachments/<файл>|<файл>]]
```
3. Вложения: ссылки `a[href*=DownloadFile]` (`/SP/SPChat/DownloadFile?messageId=…&docId=…&filetype=…&backRoute=…`). В контексте страницы `fetch(url,{credentials:'include'})` → blob → якорь с `download` скачивает файл в `~/Downloads` Mac (нужен доступ к папке Downloads: `device_request_folder_access`; он же виден как `$HOME/mnt/Downloads`). Затем `cp -n` в `Messages/edu portal/attachments/` (сравни md5 с уже имеющимся одноимённым файлом; временные скрытые файлы `.XXXX.com.anthropic.claudefordesktop.*` опознавай по размеру/типу `file`).

## Шаг 6. Базы знаний

Ссылки на источники — wikilinks вида `[[Messages/mail/<имя>|…]]`, `[[Messages/edu portal/<УЧИТЕЛЬ>/<имя>|…]]`, вложения `[[Messages/.../attachments/<файл>|<файл>]]` (в PUBLIC — `[[<папка PUBLIC>/attachments/<файл>|…]]`, школьные общие файлы копировать в `PUBLIC/attachments/`).

4. Переименуй обе папки на сегодняшнюю дату (`mv`), затем замени старое имя папок во всех `.md` (ссылки внутри баз, README, CLAUDE.md, SKILL.md не трогать).
